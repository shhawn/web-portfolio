인슈랩스 기업 홈페이지

  • HTML
  • CSS
  • JAVASCRIPT
  • PHP

인슈어테크 기업의 전문성을 기술적으로 구현한 기업 홍보 웹사이트입니다. 스크롤 기반의 인터렉션 라이브러리를 활용하여 콘텐츠의 노출 타이밍을 제어했습니다.
이를 통해 사용자가 정보를 순차적으로 습득할 수 있는 최적의 탐색 흐름을 구축하는 데 집중했습니다.
기획 단계부터 퍼블리싱 구현 가능 여부를 검토하며, 효율적인 UI 구조를 역으로 제안했습니다. 또한, 다양한 디바이스와 브라우저 환경에서도 레이아웃이 무너지지 않도록 유동적인 반응형 그리드를 설계하여 최종 결과물의 완성도를 높였습니다. PHP를 활용해 제휴 및 문의 폼의 서버 연동을 구현함으로써, 실질적인 데이터 처리가 가능한 웹 서비스를 완성했습니다.
