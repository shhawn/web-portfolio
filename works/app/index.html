앱 제작 - Web App

  • HTML
  • CSS
  • JAVASCRIPT
  • PHP

웹뷰 방식을 채택한 다수의 앱 프로젝트를 수행하며, UI 퍼블리싱부터 서버 데이터 연동까지 폭넓은 개발 범위를 소화했습니다.
기획 요구사항에 맞춰 PHP와 바닐라 자바스크립트로 직접 비즈니스 로직을 구현하였고, 이 과정에서 효율적인 스크립트 작성 역량을 길렀습니다.
특히, 실제 마켓에 출시되어 운영 중인 서비스의 실사용자 데이터를 직접 다루며 안정적인 플랫폼 운영을 경험했습니다.
또한 네이티브 개발자와의 원활한 소통을 통해 웹과 앱 간의 브릿지 기능을 설계하는 등 하이브리드 앱 특유의 인터렉션을 최적화하는 데 주력했습니다.
